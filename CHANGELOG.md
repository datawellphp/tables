## [v0.1.0](https://github.com/datawellphp/tables/commits/v0.1.0) - 2026-11-06

First release of Datawell Tables.

- An HTTP layer that serves a data source's schema and query results to the browser.
- A schema-driven React table component, published into your app with `vendor:publish`.
- Requires `datawell/datawell` ^0.1, PHP 8.3+ and Laravel 12 or 13.
